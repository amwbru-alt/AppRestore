# ReVivo: проверка сети и оплаты

Проверен исходный коммит `17550c719ee25c6dc0fa171719a8e2e64dbdf113`
репозитория `amwbru-alt/AppRestore` и изменения этого форка. Это статический анализ
исходников и автоматические проверки транспорта, не перехват трафика готовых
Windows/macOS-бинарников. Репозиторий форкнут с `J3ckJ/AppRestore`.

## Обнаруженные направления

| Направление | Что передавалось / назначение | Решение в ReVivo |
| --- | --- | --- |
| `itunes.apple.com` | Поисковая строка, ID/bundle ID, страна витрины; цены и метаданные | Разрешено; требуется для App Store |
| `*.mzstatic.com` | URL изображений и иконок Apple | Разрешено |
| Apple App Store через ipatool | Вход Apple ID, 2FA, cookie/токены сессии, история покупок, права и загрузка | Сохранено напрямую в Apple; это не сервер автора |
| Публичные Apple-хосты, TCP 443 | Проверка доступности сети | Сохранено, без авторизационного payload |
| GitHub `J3ckJ/AppRestore` | Проверка и загрузка обновлений программы исходного автора | Изменено на `amwbru-alt/AppRestore`; имена архивов ReVivo |
| `ipafilezone.com` | Поисковая строка в сторонний каталог | Заблокировано |
| `search.brave.com`, DuckDuckGo | Поисковые запросы для нахождения App Store ID | Заблокировано |
| `web.archive.org` | Запросы CDX и страниц архива, в том числе текст поиска | Заблокировано, переключатель в основном GUI отключён |
| `t0.gstatic.com` | Имя сайта для favicon | Заблокировано; при отсутствии Apple-иконки используется заглушка |
| Прочие внешние URL изображений | URL картинки из найденных метаданных | Заблокированы, кроме Apple mzstatic |
| USB / локальный usbmuxd, `127.0.0.1:27015` на Windows | Связь с подключённым устройством через локальный сервис Apple | Сохранено |

Не найдены собственный API-сервер исходного автора, Sentry/аналитика, обработчики
приёма платежей, банковские реквизиты, криптокошельки, Stripe/PayPal/YooMoney,
серверная админка и база платных аккаунтов. Слово `purchase` в коде относится к
операции Apple получения лицензии приложения. Программа проверяет цену и не
покупает новые платные приложения. Сам проект бесплатен.

## Где проверено

- `apprestore_core/catalog.py`: поиск Apple и IPA Filezone.
- `apprestore_core/web_discovery.py`: Brave/DuckDuckGo.
- `apprestore_core/delisted_search.py`: Internet Archive.
- `apprestore_core/region_probe.py`: витрина Apple, собственный HTTP GET.
- `apprestore_gui/icons_cache.py`: Apple artwork и Google favicon fallback.
- `apprestore_gui/updater.py`: GitHub Releases и загрузка архивов.
- `apprestore_gui/auth_pty.py`, `quick_session.py`, `apprestore_core/tools.py`,
  `ipatool_api.py`: запуск ipatool, вход Apple ID, устройство.
- `packaging/patches/`: патчи App Store и обработка Apple-редиректов.
- `apprestore_core/license_gate.py`, `license_guard.py`, `purchase_grant.py`:
  выдача только бесплатной новой лицензии, согласие и журнал.

## Внесённые меры

`apprestore_core/network_policy.py` разрешает публичные метаданные только по HTTPS
к `itunes.apple.com` и `mzstatic.com`/его поддоменам. Проверяется точное имя хоста,
нет авторизации в URL, разрешён порт 443, метод GET без тела. Необязательные
сторонние адреса блокируются **до создания opener / DNS-запроса**.

Все найденные HTTP-запросы Python runtime проходят через эту политику. Отдельный
HTTPRedirectHandler повторно проверяет каждый редирект. Отсутствие разрешения не
приводит к отправке запроса на исходный внешний адрес. Заодно проверка сохраняет
самостоятельный opener без глобальных cookie/auth handlers.

Обновления используют только API релизов вашего форка и его download-пути;
переход к GitHub object storage разрешён лишь после доверенного URL обновления.
SHA-256 и существующие проверки ZIP/подмены обновления сохранены. GitHub остаётся
внешней платформой, хотя репозиторий принадлежит вам. Новые релизы надо собирать и
публиковать в вашем форке.

Встроенный каталог удалённых приложений остаётся локальным. Внешний архив в UI
отключён; отсутствие иконок извне компенсируется заглушкой. Это может уменьшить
полноту поиска удалённых приложений по сравнению с исходной программой.

Сеансы и журнал остаются на компьютере. Перенаправление секретов на новый сервер,
сбор телеметрии и серверная синхронизация не добавлены. По уточнению владельца
подключение собственных серверов и оплаты отложено, приложение бесплатное.

## Границы заключения

Политика Python не является системным firewall и не перехватывает сетевые вызовы
Go-бинарника ipatool, pymobiledevice3, ОС или настроенного пользователем прокси.
Для ipatool сохранена сборка из закреплённого исходника с проверенными по SHA-256
патчами; неподтверждённые внешние бинарники отдельно не проверялись. Служебные
TLS/DNS-запросы, пользовательский прокси и системные сетевые компоненты зависят
от окружения. Отсутствие утечки в конкретной готовой сборке требует проверки
трафика на целевых ОС с тестовым аккаунтом владельца.

Процесс **сборки** закономерно обращается к GitHub, PyPI, Go и зеркалам зависимостей.
Это не пользовательская телеметрия. Исторические CLI-инсталляторы изменены на
ресурсы вашего форка, но их закреплённые ipatool-архивы сначала нужно опубликовать
самостоятельно. Не заменяйте URL/хэши непроверенными бинарниками.

Ни вход на реальный Apple ID, ни покупка, ни платёж, ни установка на реальный
iPhone в ходе этой проверки не выполнялись. Финансовых списаний не производилось.
