# Заказы и выдача промокодов на сайте

Список заказов можно фильтровать по номеру, оплате, активации и диапазону дат.
Диапазон использует UTC: обе выбранные даты включаются полностью. Неверные даты
и обратный диапазон отклоняются сервером. Все запросы остаются ограничены
текущим авторизованным покупателем. Счётчики над списком учитывают все его коды.

Кнопки «Копировать коды» и «Скачать TXT» получают свежие данные текущей страницы,
с учётом действующих фильтров. Выдаются только коды оплаченных заказов со статусом
«Не активирован» и сохранённым текстом. Активированные, аннулированные, возвращённые
и исторические коды без текста не включаются. Это снимок статуса на момент запроса:
другой исполнитель может активировать переданный код после проверки.
В TXT записан один код на строку; файл не отправляется сторонним сервисам.
На HTTP, когда буфер обмена недоступен, открывается поле ручного копирования.
Поле очищается при закрытии, обновлении списка, выходе и уходе со страницы.

Каждый заказ имеет ссылку на поддержку с номером заказа и статусом. Она не
подставляет промокоды, Apple ID, почту или пароль. Пользователь сам отправляет
сообщение в Telegram. Перед оплатой показывается итоговая сумма, а при отключённых
платежах кнопка покупки недоступна. Живое обновление возобновляется при возврате
на страницу через кеш браузера, не создавая повторных таймеров.

Для обновления достаточно обновить ветку, выполнить `npm ci` в `server/node`
и перезапустить существующий процесс Node. Миграции БД и пересборка настольного
приложения для этого обновления не нужны.
