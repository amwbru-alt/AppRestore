# Проверенная история восстановления

Список «Восстановить из истории» формируется как пересечение двух проверок:

1. Полностью обновлённая история покупок текущего Apple ID от Apple.
2. Успешно прочитанный список приложений выбранного подключённого iPhone.

Из истории исключаются установленные приложения по точному bundle ID или
совпавшему App Store ID из метаданных телефона. Название и картинка не являются
доказательством совпадения. Сгруженные placeholders не считаются установленными:
их можно восстановить. Дубликаты App Store ID удаляются.

Сохранённый кеш, неполная/отменённая загрузка и ошибка обновления истории не дают
строк восстановления. Нет телефона, ошибка доверия/опроса или сменился телефон —
список скрыт до успешной проверки. Строки без точного bundle ID не показываются.
Кнопка «Обновить» повторяет обе проверки; после установки список телефона
проверяется снова. Общие записи локального IPA/iMazing/known-apps не попадают в
основной список отсутствующих приложений без совпадения с проверенной историей.
Стандартный банковский каталог может обогатить название и иконку точного ID,
но не добавляет владение приложением. Сырой список покупок сохраняется отдельно
для проверки лицензий и подписей, а не подменяется отфильтрованным списком.

Ограничения: история Apple ID доказывает получение приложения аккаунтом, но не
установку на конкретном устройстве и не гарантирует доступность повторного
скачивания у Apple. Удалённые до первого подключения приложения, скрытые покупки,
неполные ответы Apple и записи без bundle ID могут отсутствовать. Список телефона
отражает момент опроса: после изменений на телефоне нажмите «Обновить».
Проверка на настоящих Mac/Windows, Apple ID и USB-устройствах остаётся необходимой
перед выпуском: автоматические тесты не заменяют ответы Apple и iPhone.

Приложение не покупает новые лицензии при построении этого списка.
