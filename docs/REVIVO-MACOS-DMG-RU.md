# ReVivo на macOS: DMG без ключей Apple

## Что изменено

Упаковщик автоматически создаёт `gui-dist/ReVivo-macOS.dmg` вместе с прежним ZIP.
Внутри — `ReVivo.app`, ярлык `Applications` и инструкция `INSTALL-RU.txt`.
Установщик не требует Apple Developer ID или ключа notarization для создания образа.

DMG проверяется через `hdiutil verify`, монтируется только для чтения, затем
проверяются исполняемый файл, ярлык Applications и целостность подписи .app.
Образ отключается после проверки. SHA-256 включается в релизный `SHA256SUMS.txt`.
ZIP сохраняется для штатного автообновления.

Это способ упаковки и установки, **не обход Gatekeeper**. Сборка использует
локальную ad-hoc подпись, не удостоверяющую личность разработчика, и не имеет
подтверждения notarization Apple. Поэтому автоматический запуск без предупреждений
не гарантируется. Выдавать такой образ за проверенный Apple было бы неверно.

## Как установить

1. Скачать DMG из доверенного релиза своего репозитория; при необходимости сверить SHA-256.
2. Открыть DMG и перетащить ReVivo в Applications / Программы.
3. Извлечь образ и запустить ReVivo из Программ.
4. Если macOS сообщает, что не может проверить разработчика/вредоносность:
   открыть Системные настройки → Конфиденциальность и безопасность → Всё равно открыть,
   если эта кнопка доступна после попытки запуска. Подтвердить выбор.

Это разовое разрешение конкретной программы, а не отключение защиты macOS.
Может потребоваться пароль администратора; политика управляемого Mac может запретить
такое разрешение. Если macOS прямо сообщает об обнаруженном вредоносном ПО,
повреждённой подписи или файл отличается от опубликованной суммы, не игнорируйте
такое сообщение: скачайте файл заново из доверенного источника и проверьте сборку.

Формулировки окон зависят от версии macOS. Формат .dmg не устраняет ошибки
архитектуры, повреждение файла, запрет организации или вердикт антивирусной защиты.
Для запуска с обычным доверием Gatekeeper всё равно нужны Developer ID, Hardened
Runtime и успешная notarization. Они не могут быть заменены переименованием ZIP в DMG.

## Как получить DMG

На macOS после стандартной сборки PyInstaller и локального патченного ipatool
выполнить существующую команду `python packaging/package_gui.py ...`, описанную
в [основном руководстве](REVIVO-GUIDE-RU.md). DMG создаётся автоматически после
проверок ZIP. Для повторной упаковки уже подготовленной .app:

```bash
python packaging/make_dmg.py --app dist/ReVivo.app --out gui-dist/ReVivo-macOS.dmg
```

Требуются macOS и системные `hdiutil`, `ditto`, `codesign`. Linux/Windows эту
нативную упаковку не выполняют. В GitHub Actions workflow **GUI build** также
собирает и прикрепляет DMG в артефакте `ReVivo-GUI-macOS`. Для изменений упаковки
и GUI добавлен автоматический запуск workflow в pull request. Релизный workflow
публикует DMG рядом с ZIP и включает его SHA-256 в общий файл сумм.

Текущий workflow собирает архитектуру выбранного macOS runner, не universal binary.
Проверяйте соответствие Apple Silicon/Intel компьютеру пользователя. Настоящая
проверка установки требует загрузки DMG браузером и запуска на отдельном Mac с
включённым Gatekeeper; Linux-тесты упаковщика её не заменяют.

- https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac
- https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution
