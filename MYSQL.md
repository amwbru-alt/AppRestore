# MySQL теперь доступна только Node.js-серверу

AppRevive больше не подключается к базе напрямую и не читает mysql.json.
В клиенте нет MySQL-драйвера и реквизитов БД. Файл .env с DB_HOST,
DB_USER, DB_NAME, DB_PASSWORD нужен только на сервере Node.js.

[Полная инструкция: HTTP API по IP, запуск сервера и настройка клиента](server/node/README.md).

Существующие таблицы сохраняются: apprevive_promo_codes,
apprevive_promo_redemptions, apprevive_app_catalog. Импортировать схемы
повторно не нужно, если они уже созданы.

Старые сборки с прямым доступом и переданные mysql.json нужно заменить:
новый код не меняет установленные ранее приложения автоматически.
