# AppRevive GUI

PySide6 desktop UI matching the v5 mockup.

```bash
pip install '.[gui]'
apprevive-gui --demo
python -m apprevive_gui --demo --screenshot-dir /tmp/gui-shots
```

Fonts: Onest (OFL) in `resources/fonts/`.
Artwork: public iTunes Lookup API, cached under the AppRevive cache directory.
